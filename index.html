03

My values

Four things I refuse to trade away, in any project.

🧱 Product Engineering & Clean Code

The final product is the result of a solid construction process. I practice Clean Code and clean architecture so the software is not only functional, but readable, testable and scalable.

🎨 UX, Aesthetics & Intuitiveness

Beautiful interfaces are not enough — they have to work. I reduce the user's cognitive load through fluid flows, high-fidelity design and intuitive interfaces. And I personalize: every client, school and student should feel the product was made for them, not adapted to them.

♿ Inclusion & Clarity

People-focused development: accessibility (A11y), semantically correct code and transparent communication — both in the interface for the user and in the code for the team.

🎯 Impact First

Technology is a means, not an end. I align technical decisions of excellence to deliver real value for the person using it and results for the business.
